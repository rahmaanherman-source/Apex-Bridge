# APEX VERIFICATION RECORD

Any material fact, capability, account state, deployment, integration, entitlement, compliance claim, test result, or completion claim verified for this repository MUST be recorded in `VERIFICATION/LEDGER.md` before being represented as VERIFIED/GREEN.

Truth states: VERIFIED, OBSERVED, DOCUMENTED, UNVERIFIED, BLOCKED, CONFLICTING, OUTDATED.

Each entry must include: what was verified; repository/component; exact evidence source; date/time; verifier/tool; result; expiration/recheck date when applicable; limitations.

No-fake-green rule: UI labels, old AI responses, compilation alone, or documentation alone do not prove VERIFIED.

Cross-repository facts must be recorded in each affected repository and reconciled by the APEX master verification system.
